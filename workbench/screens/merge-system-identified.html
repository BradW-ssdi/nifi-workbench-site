Merge Candidate Queue

The system identified these records as potential duplicates. You can take action using the following options:

  • Merge: To merge records, select two or more candidates in the Merge column. Optionally, select a Surviving ID. If no Surviving ID is selected, then the oldest (first) patient ID will be the Surviving ID. After making your selections, click Merge.
  • Remove from Merge: To remove a patient from future merges, select a patient in the Merge column and click Remove from Merge. This will flag the patient to NOT be included in future merge logic until/unless the patient record is updated in the future.
  • No Merge: Clicking this button allows you to indicate that none of the candidates in the merge group should be merged and to move to the next set of merge candidates.
  • Skip: Clicking this button allows you to skip the current merge candidate list to get to the next set of merge candidates. Any skipped merge candidate groups are moved to the end of the merge candidate group queue for later review.
