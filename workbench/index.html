Code-first proof of concept. There is one copy of every token and component, and the views use it. The workbench renders the same CSS the application will use, so every specimen is live. Show code on any example shows its exact HTML and the system CSS behind it. The Figma library matches this one file for file, with the same tokens, components, and screens. Every component is verified for 508 / WCAG AA.
