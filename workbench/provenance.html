Provenance

Where each design-system pattern is produced in the application codebase today. Paths are relative to src/main/resources/ in the app repo. The Duplicates column is the consolidation backlog: every parallel copy listed there can collapse into one shared fragment or component. The same data lives in the variant catalogue's Provenance Map sheet and in docs/provenance.md.

Three producer shapes exist in the app: shared fragments (breadcrumbs, main nav, global toast — already consolidated), parallel copies (same markup pasted per screen or entity — the cheapest wins), and inline-by-class (consolidated only by Bootstrap class — replaced screen-by-screen as pages are touched).
