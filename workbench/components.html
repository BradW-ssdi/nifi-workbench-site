Button with icon

Accessibility: 508 / WCAG AA
  • Use a real <button>. Do not use a styled <a> or <div> with a click handler.
  • Icons inside labeled buttons carry aria-hidden="true"; the visible text is the accessible name.
  • Disable with the disabled attribute. It takes the control out of the tab order, which a class does not.
  • Focus is a 3px ring with a white gap, and it is never removed. Contrast: white on #2C6777 = 7.0:1, on #D40032 = 6.3:1. Both pass AA and the primary passes AAA.
  • Min target 40px tall. 2.5.8 AA asks for 24px, so there is margin. Reflows without clipping at 320px width (400% zoom).

Accessibility: 508 / WCAG AA
  • Real <table> semantics: <th scope="col"> on every header and a <caption> (visually hidden is fine) naming the table.
  • Sorting is an action, so the header control is a <button class="ds-sort-btn">, never a link. Only the sorted column carries aria-sort="ascending|descending", and each re-sort is announced through the page's live region.
